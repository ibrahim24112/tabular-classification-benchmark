# References and datasets

## Datasets

### Statlog German Credit Data

Hofmann, H. (1994). *Statlog (German Credit Data)*. UCI Machine Learning Repository. DOI: 10.24432/C5NC77.

Source: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data

### Bank Marketing

Moro, S., Rita, P., and Cortez, P. (2014). *Bank Marketing*. UCI Machine Learning Repository. DOI: 10.24432/C5K306.

Source: https://archive.ics.uci.edu/dataset/222/bank+marketing

The `duration` predictor is excluded from the modeling dataset because it is only known after the campaign call. The implemented task represents a pre-contact targeting scenario.
